1. 录音与转写

点了开始录音，却没有文字

  • 确认已在系统设置中允许本 App 使用麦克风：设置 → 时刻 → 麦克风。
  • 确认识别模型已下载完成（设置页会显示模型占用）。未下载时无法转写。
  • 识别按语音停顿切分，通常每 8~10 秒出一批文字；刚开口时短暂空白属正常。

识别结果不准确

  • 本 App 使用本地离线模型，准确率受口音、语速与背景噪声影响。
  • 尽量靠近说话人，避免多人同时说话；嘈杂环境建议开启降噪。
  • 可在设置中切换识别语言（中文 / 英文 / 粤语 / 日文 / 韩文）。选错语言会显著降低准确率。
  • 标点由模型输出决定，部分语言或场景标点较少属正常现象。

锁屏或切到其他 App 后录音停止

  • 本 App 已声明后台音频权限，正常情况下锁屏会继续录音。
  • 若被来电、其他音频 App 或系统资源回收中断，录音会保存已录制的部分。
  • 低电量模式下系统可能限制后台运行，建议录音时保持充电或关闭低电量模式。

2. 模型下载

需要下载多大的文件

模型体积是否必需
语音识别模型约 239 MB必需（不下载无法转写）
文字纠错模型约 397 MB可选（提升标点与错字表现）

模型只在首次使用时下载一次，之后完全离线运行。建议在 Wi-Fi 环境下下载。

下载失败或卡住

  • 检查网络连接，切换到其他网络后重试。
  • 下载源为 Hugging Face（失败时自动尝试镜像），部分地区可能访问受限。
  • 确认设备剩余存储空间足够（建议至少留出 1 GB）。
  • 仍失败时，请发邮件并附上日志文件。

3. 订阅与购买

如何恢复已购买的订阅

在设置页点击“恢复购买”，使用购买时相同的 Apple ID 登录即可。订阅与 Apple ID 绑定，不随设备变化。

如何取消订阅

iOS 设置 → 你的 Apple ID → 订阅 → 时刻 → 取消订阅。仅卸载 App 不会取消订阅。

如何申请退款

支付与退款由 Apple 处理，请访问 reportaproblem.apple.com。

订阅到期后我的录音和文字会消失吗

不会。已产生的录音、文字稿与译文始终保留在设备上，可继续查看与导出；订阅只影响新增的高级功能。

4. 数据与隐私

录音和文字存在哪里

全部保存在本机 App 沙盒内，不上传服务器。详见 隐私政策。

音频会一直保留吗

默认保留 7 天，可在设置中调整；文字稿长期保留，直到你删除对应录音。

如何彻底删除数据

删除单条录音可在历史列表中左滑删除；彻底清除请卸载 App，系统会删除沙盒内全部数据。

换手机会丢失录音吗

会。本 App 不提供云端同步。换机前请在详情页导出需要保留的文字内容；音频本身不会随 iCloud 备份之外的途径迁移。
